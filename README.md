# Prompt Compression and Token Budgeting using LLMLingua

A research prototype for question-aware prompt compression and token-budget enforcement on long enterprise logs and multi-page PDFs.

## Goals

- Preserve system instructions and the user's question unchanged.
- Extract and normalize text from PDFs and log files.
- Split context into chunks and rank chunks by relevance to the question.
- Compress context with LLMLingua at configurable target ratios.
- Enforce a per-request token budget before sending context to a downstream model.
- Record token counts, latency, compression overhead, and estimated API cost.
- Benchmark 1x, 2x, 3x, and 5x settings on summarization, extractive QA, and multi-hop QA.

## Status

Initial repository scaffold. Benchmark scores and degradation thresholds must be generated by running the evaluation harness on the selected datasets and models; no performance results are claimed yet.

## Planned structure

- `src/prompt_budget/`: middleware, chunking, ranking, compression, telemetry.
- `benchmarks/`: dataset schema and evaluation runner.
- `configs/`: experiment and model configuration.
- `tests/`: unit tests for budget enforcement and prompt preservation.
- `docs/`: architecture, methodology, and report notes.
